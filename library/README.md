# 雪籠りの図書館

雪に降り籠められた田舎の図書館の箱庭。three.js で、建物・本・人・雪・光をすべてコードで作る（画像も 3D モデルも使わない）。
「箱庭」本体（リポジトリ直下）とは別の作品。

- `index.html`：これ 1 枚で動く。ダブルクリックでブラウザで開ける（three.js は jsDelivr から読む）
- `tools/shot.cjs`：ヘッドレス Chromium（SwiftShader）で撮る。three.js は同梱の `vendor/three` を返すのでネット不要

```sh
node library/tools/shot.cjs shots/lib4.png "view=4&t=30"   # 視点 4 を、時刻 30 秒で止めて撮る
```

URL の引数：`view=1..7`（最初の視点）、`t=秒`（時刻を止める）、`ui=0`（文字を隠す）、`follow=1`（ついて歩く）、`cam=x,y,z,tx,ty,tz`（好きな位置から。確かめ用）、`q=low`（霧の中の光と隅の暗さを切って軽く）、`tone=aces`（色調を AgX から ACES に戻して見比べる）、`msaa=0`

視点：一 全景／二 雪の夜道／三 玄関／四 閲覧室／五 ストーブ／六 土間・上がり框／七 書庫。ほかに「ついて歩く」（バスを降りた人と玄関まで歩き、中に入ったら閲覧室へ移る）。
操作：1〜7 キー、ドラッグで見回し（手を離して 4 秒で元の構図へ戻る）、ホイール・ピンチで寄る。「巡回」で 16 秒ごと。M で音、H で文字を隠す、F で全画面。

仕組みのメモ
- 壁に影を落とさない安い点光源は壁を素通りするので、描画時に「この点はどの部屋か」を調べ、灯りごとに決めた部屋の中だけを照らす（`patch()`）
- 被写界深度は半分の解像度で、ピントの外の明るい点ほど丸く広がる集め方（scatter-as-gather）。その後に光のにじみ（bloom）
- 雪・湯気・煙は状態を持たず、時刻だけから位置を決める
- 霧の中の光：灯りごとに、視線に沿った逆 2 乗の明るさを表面までの長さで積分した閉じた式で足す。灯りが手前の物に隠れているかは灯りごとに 1 回だけ深さで調べる
- 隅の暗さ（SSAO）は法線を深さから作り直す。ピントは画面中心の深さを GPU の中で測って追う
- 音は全部その場で合成（雑音と打撃を共鳴に通す）。置き場所と部屋で大きさ・こもり・左右・残響を変える
- 手法の研究と取り入れ候補は [RESEARCH.md](RESEARCH.md)
