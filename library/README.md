# 雪籠りの図書館

雪に降り籠められた田舎の図書館の箱庭。three.js で、建物・本・人・雪・光をすべてコードで作る（画像も 3D モデルも使わない）。
「箱庭」本体（リポジトリ直下）とは別の作品。

- `index.html`：これ 1 枚で動く。ダブルクリックでブラウザで開ける（three.js は jsDelivr から読む）
- `tools/shot.cjs`：ヘッドレス Chromium（SwiftShader）で撮る。three.js は同梱の `vendor/three` を返すのでネット不要

```sh
node library/tools/shot.cjs shots/lib4.png "view=4&t=30"   # 視点 4 を、時刻 30 秒で止めて撮る
```

URL の引数：`view=1..7`（最初の視点）、`t=秒`（時刻を止める）、`ui=0`（文字を隠す）、`msaa=0`（アンチエイリアスを切る）

視点：一 全景／二 雪の夜道／三 玄関／四 閲覧室／五 ストーブ／六 二階回廊／七 書庫。1〜7 キー、ドラッグで見回し、ホイール・ピンチで寄る。「巡回」で 16 秒ごとに巡る。

仕組みのメモ
- 壁に影を落とさない安い点光源は壁を素通りするので、描画時に「この点はどの部屋か」を調べ、灯りごとに決めた部屋の中だけを照らす（`patch()`）
- 被写界深度は半分の解像度で、ピントの外の明るい点ほど丸く広がる集め方（scatter-as-gather）。その後に光のにじみ（bloom）
- 雪・湯気・煙は状態を持たず、時刻だけから位置を決める
